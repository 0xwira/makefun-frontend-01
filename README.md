FIELDNOTES is a bright make.fun bounty explorer for AI builders. This static, no-build frontend combines a sidebar, category cards, and a master-detail board to explore live prize pools, rules, rewards, leaderboards, and public profiles through make.fun's public API, using a short in-memory cache to keep browsing responsive.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in a desktop browser.
